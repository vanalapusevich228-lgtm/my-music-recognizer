MY MUSIC RECOGNIZER — первая экспериментальная версия

ЧТО ЭТО:
Веб-страница для iPhone/Safari. Она создаёт локальную базу аудиоотпечатков из выбранных аудиофайлов и пытается распознавать музыку, звучащую через микрофон iPhone.

ВАЖНО:
- Это экспериментальный прототип, не коммерческий Shazam. Точность зависит от громкости, шума, качества записи и длины фрагмента.
- Для микрофона нужен HTTPS. Просто открыть index.html из приложения «Файлы» недостаточно.
- Данные IndexedDB хранятся в Safari на конкретном устройстве. Не очищай данные сайта, иначе база может пропасть.
- Сначала попробуй на 5–10 песнях и сравни результат. Большие коллекции могут занимать заметную память и долго индексироваться.
- iOS/Safari может ограничивать размер выбранных файлов и длительность работы страницы в фоне. Не сворачивай Safari во время распознавания.
- В этой версии исходные аудиофайлы не загружаются на сервер; в браузере сохраняются только названия и аудиоотпечатки.

ФАЙЛЫ:
index.html — страница
style.css — оформление
app.js — логика базы и распознавания

ПУБЛИКАЦИЯ:
Нужно разместить все три файла на статическом HTTPS-хостинге. Например, GitHub Pages:
1. Создай аккаунт на github.com (если его нет).
2. Создай новый репозиторий с именем my-music-recognizer.
3. Загрузи в корень репозитория index.html, style.css и app.js.
4. Открой Settings → Pages.
5. В разделе Build and deployment выбери Deploy from a branch.
6. Выбери ветку main и папку /(root), нажми Save.
7. Подожди публикации и открой выданный адрес вида https://ИМЯ.github.io/my-music-recognizer/ в Safari.
8. Нажми «Добавить музыку» и выбери аудиофайлы из «Файлы».
9. На iPhone нажми «Добавить музыку» и выбери несколько аудиофайлов в приложении «Файлы» (выбор целой папки в Safari на iPhone может быть недоступен).
10. Разреши Safari доступ к микрофону при первом распознавании.

ПРИМЕЧАНИЕ:
На iPhone удобнее сначала загрузить 3 файла в репозиторий через сайт GitHub в режиме «Desktop Website» или с компьютера. Не переименовывай файлы и не раскладывай их по папкам.
